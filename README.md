# Skogsdag

A mobile web app for forestry contractors in northern Sweden, built as a prototype for Norther Loggers, Jokkmokk.

- Open the app: https://aneesrehman89.github.io/skogsdag/
- Install guide (Android and iPhone): https://aneesrehman89.github.io/skogsdag/install.html
- Privacy: https://aneesrehman89.github.io/skogsdag/privacy.html

Public data: Swedish Forest Agency (Skogsstyrelsen) open data, Open-Meteo, TED. Map © OpenStreetMap contributors. Leaflet (BSD-2-Clause). Plus Jakarta Sans (SIL OFL).
